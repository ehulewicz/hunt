# Frontend rules

- Use the governed grayscale and blue-gray tokens in `src/styles/tokens.css`.
- Prefer flat bordered lists and 2–4px corners. Shadows belong only on transient overlays.
- The document owns vertical scrolling; avoid nested vertical scroll regions.
- Next.js and TypeScript are presentation and browser-auth concerns only. Business logic belongs in Python.
- Reuse the persistent workspace layout for Dashboard, Jobs, Settings, and Integrations.
